# SharkNet website

Static, dependency-free one-page launch site for **SharkNet v3.2.0**.

## Included
- Official SharkNet branding and real v3.2.0 application screenshot.
- Direct Windows installer download button for v3.2.0.
- Feature and control-mode overview.
- SharkNet vs. alternatives comparison with a link to the detailed project benchmark.
- Installation / first-run walkthrough.
- Honest review plus Pros & Cons.
- System requirements, privacy, sponsorship, release hash and FAQ.
- Memorial dedication: Sadaqah Jariyah in loving memory of the developer's father.
- Animated one-page UX: scroll reveal, icon motion, pointer tilt, active navigation, live scroll progress, ambient network motion and back-to-top control.
- Motion automatically reduces when the visitor has `prefers-reduced-motion` enabled.

Upload the contents of this folder to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any static web host. No build step is required.


## Comparison update
The comparison section now covers SharkNet, NetCut, SelfishNet and NetLimiter, with SharkNet-specific LAN-control advantages highlighted and an explicit note that NetLimiter is deeper for per-application control on the local Windows PC.

Dark theme is the default on first visit. A user-selected Light or Dark preference is still remembered locally.
