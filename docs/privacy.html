PRIVACY

Local-first by design.

SharkNet requires no account, uses no SharkNet cloud backend, and includes no telemetry.

Local storage

Settings, device names and supported saved rules may be stored locally. Restore Saved Rules is optional and disabled by default.

Visited-site history

Visited-site history is session-only in the current application and is not persisted to the local database.

Diagnostics

Diagnostics are local and read-only by design.

Network traffic

SharkNet processes local network traffic to provide monitoring and control functions. It does not decrypt TLS content.
